All data is fictional and generated by a script with a fixed random seed. No real employer, customer or employee data was used. This project was built with AI assistance.

The staffing need uses a deliberately simple formula (workload ÷ 85% occupancy), not Erlang C, and has no shrinkage. The SQL files calculate the building blocks; this page only adds up the rows you select and divides.
